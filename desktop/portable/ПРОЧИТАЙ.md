# Folder distribution

This directory supports the optional developer folder build:

    pwsh ./build.ps1 -Portable -OutputDirectory ./artifacts/folder-portable

Move that complete folder together; its profile is in data/. The public release
is instead ONE EXE from build-single-file.ps1, with settings in AppData. Normal
users should download that release EXE, not individual files from this directory.

Ctrl + Alt + F8 pauses; Ctrl + Alt + F12 restores the Windows cursor and exits.
Startup is opt-in; refresh its path after moving a distribution.
