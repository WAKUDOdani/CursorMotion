# Provenance

CursorMotion is maintained by WAKUDO Dani. It brings a GPU-rendered cursor to
the ordinary Windows desktop, with native cursor presentation, theme packs,
independent forms, shape transitions, a tray host and a settings application.

The initial SDF cursor geometry and quadratic exposure integration were adapted
from the Windows OBS Lua script **Motion Blur Cursor**, supplied as part of
`cursor-skin-fx-3.0.0/motion_blur`. The supplied license is the Unlicense, retained
in [ORIGINAL-LICENSE.txt](../ORIGINAL-LICENSE.txt). The original script is preserved
at [reference/motion_blur_cursor.lua](reference/motion_blur_cursor.lua).

No upstream author name is invented where the supplied source does not name one.
OBS and its libraries are not bundled or required by CursorMotion. The desktop
host, recovery process, UI, added forms/materials, packaging and integration are
CursorMotion implementation code under [MIT](../LICENSE).

The UI and repository presentation draw inspiration from the author's
[WakuShare](https://github.com/WAKUDOdani/WakuShare). WakuShare application code
and its CapCut runtime are not bundled. Download buttons/docs are adapted to
CursorMotion's blue/violet identity and actual functionality.

Electron/Chromium, .NET, Vortice, SharpGen, React, icons and Inter retain their
respective licenses and notices. See [THIRD-PARTY-NOTICES.txt](../THIRD-PARTY-NOTICES.txt).
