# Что нового

## В разработке — 3.10.0

- Пользовательские пресеты: сохранить полный профиль, применить, обновить,
  удалить с подтверждением, импортировать и экспортировать отдельный пресет.
- Краткие пояснения настроек непосредственно в окне приложения.
- Windows 11: физические GPU-кадры создаются без повторного DPI-масштабирования
  Windows при переходах между мониторами. Моушн и морфинг не менялись.
- Скруглённое обрамление настоящих скриншотов в README.
- Встраиваемый стартовый профиль для новых установок и сброса. Авторские
  стартовые значения пока не выбраны; существующие профили не заменяются.

## 3.9.0 — Portable в одном EXE

- Один самостоятельный Windows x64 EXE с включёнными .NET и Electron.
- Проверенный кэш компонентов и автоматическое восстановление повреждённой копии.
- Настройки в AppData; запуск не создаёт файлы рядом с EXE.
- Автозапуск использует основной EXE, включая имена с пробелами и кириллицей.
- Новый публичный репозиторий, README RU/EN, инструкции и проверяемый выпуск.
- Принятые моушн, геометрические переходы и совместимость с NVIDIA из3.8.5 сохранены.

## 3.8.5 — Совместимость записи

- Компактные нативные кадры без изменения видимых пикселей курсора.
- Опциональный режим NVIDIA; пользователь подтвердил корректную запись.
- Пользователь также подтвердил отсутствие второй стрелки в Discord и что
  ранее наблюдавшееся мигание больше не проявляется.

## Ранее

Нативный вывод поверх обычных окон/уведомлений, whole-image motion blur, плавные
переходы форм, независимые параметры четырёх основных указателей, resize-формы,
настоящие образцы материалов в интерфейсе, стеклянные наборы и трей.
